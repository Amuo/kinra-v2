## Confirmed defects repaired in this pass

- **33–36, 41:** Program filters compared English option values with already-translated metadata. Canonical matching now happens before localization; displayed choices use each template's authored language. Tests cover matching IDs and localized searches in EN/BS/DE.
- **22, 41:** Saved original templates were misreported as unavailable because saved-item lookup only knew archived references. Runnable template and exercise bookmark titles now follow the selected language; missing IDs remain explicitly unavailable.
- **58, 64:** Generic weekday chips rendered English abbreviations despite translated accessible keys. Visible labels now translate while stored day numbers remain canonical.
- **72:** Promotion expiry is a date-only schema but used a date-time input. It now preserves a date-only value; regression covers a changed date without appended time.
- **70–75:** Directory now offers Discover/Saved/My listings, reversible bookmarks, 4.5+ rating filtering and opening-hours/address detail. No fabricated views/download counts.
- **03–04:** Auth adds a visible show-password checkbox, explicit field accessible names and password-manager autocomplete semantics.
- Localization checker now covers schema enum choices plus exercise category/muscle labels, in addition to existing explicit UI and configuration labels.
