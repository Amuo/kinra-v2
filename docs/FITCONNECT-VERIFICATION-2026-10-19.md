# FitConnect comparison and Kinra verification

Evidence date: 19 October 2026; execution continued into 20 October UTC. This audit compares the supplied client-account evidence with Kinra. It does **not** establish complete FitConnect parity or prove every feature works on every device.

## Repaired in this audit

1. Program filters previously compared translated metadata against English option values, creating false empty lists in Bosnian and German. Matching now uses canonical metadata; localized searching, bookmarks and type changes are covered by regression tests.
2. Runnable saved templates could appear unavailable. Bookmarks now resolve both original templates and archived references, with localized titles.
3. Previously adopted templates stayed in their creation language. A guarded, read-only provenance endpoint now lets unchanged original plan fields follow the selected language. Names, descriptions, progression, day titles, instructions, equipment, meal names, ingredients and quantities use authored EN/BS/DE content. Custom edits, numeric prescriptions, food macros and stored history remain intact. Unknown content versions retain their saved text.
4. Active sessions retain optional display provenance in their local drafts, allowing language changes without changing raw exercise identities, sets or completed-workout payloads. Historical edits and older drafts retain their original text.
5. Real binary downloads exposed a cache defect: a previously published PDF could still return cached bytes after being made private. New uploads use zero cache lifetime; every application download checks current metadata authorization and requests fresh Storage bytes. Post-fix tests reject unpublished resources and disconnected attachment recipients. Files already saved by a recipient cannot be recalled, and existing signed photo URLs keep their issued expiry.
6. Directory saved/own views, reversible bookmarks, rating filtering and address/opening-hours detail were completed. Promotion dates preserve date-only values; visible weekday labels, Today hints, progress milestones and assigned exercise labels translate. Authentication fields have explicit accessible names, autocomplete semantics and show-password control.

User-authored coach plans, posts, custom food names and third-party catalogue descriptions retain their author's language. Localized built-in content does not imply automatic translation of private user text. Recipe yields, grocery lists and reviewed ingredient substitutions are proposed improvements, not proven missing FitConnect capabilities.

## Release outcome

The comparison pass finished with 195 passing tests across 42 files after the paused-session sign-out correction. The browser then signed out cleanly without new console errors. All six synthetic accounts completed application-data erasure, preserving shared Auth identity as designed; the disposable test identities were subsequently removed. Independent queries confirmed no fixture Auth users, feature records, programs or Storage objects remained.
